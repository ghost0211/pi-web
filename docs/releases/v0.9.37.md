# Pi Web v0.9.37

## Codemode advanced settings

- Edit mode (`on` / `only`) and inline description budget in Settings → General.
  Zero is supported. These controls do not enable tools or modify `defaultTools`.
- Save explicitly; reload an existing live session explicitly. No session is
  silently started by the settings page. Trusted project settings may override
  the global defaults.

## Graphical MCP management

- Settings → MCP manages the CLI-shared global and trusted project `mcp.json`:
  stdio/Streamable HTTP, enabled state, exposure, timeout, descriptions,
  per-tool exposure, environment, headers and authentication options.
- Explicit two-step project trust includes extensions and skills, not just MCP.
  Global provider credentials remain unavailable to project configurations.
- Native status, reconnect and OAuth login/logout use the official SDK command
  and transports. No model prompt, parallel MCP client or new credential store.
- Configuration saves do not connect or reload automatically. Chat-only sessions,
  subagent restrictions and replaced/disabled builtins remain isolated.
- Saved secrets are masked. Ordinary saves preserve hidden authentication fields;
  JSON `null` explicitly removes OAuth options without deleting SDK login tokens.
- Revision conflicts require refresh. Malformed files are not overwritten;
  file locking, private atomic writes, symlink checks and post-lock trust/path
  checks protect edits. OAuth links require HTTPS or loopback HTTP.
- English, Simplified Chinese and Traditional Chinese interfaces.

## Verification

- 1251 tests; TypeScript, zero-warning lint and whitespace checks.
- Isolated regular and standalone builds; 15 HTTP checks on each build.
- Real SDK loopback OAuth login/PKCE/token storage/logout tested from the
  standalone bundle. Pi AI OAuth modules and QuickJS WASM assets validated.
- No production credentials or paid model calls used for feature tests.

The existing export-route dynamic-import build warning remains unchanged.
Browser/WebView and real-provider OAuth certification are outside fixture tests.
Stdio MCP dependencies must be available on the server's PATH.
