# Pi Web v0.9.38

## Pi SDK 1.0.0

- Upgrade the embedded Pi agent, AI, coding-agent and TUI dependencies to 1.0.0.
  Updating the global CLI alone does not update Pi Web's embedded runtime.
- Use the official slimmer Codemode and `models.generateImages()` APIs. Generated
  images appear in expanded tool results with click-to-preview; recorded image
  usage is counted once, without synthetic conversation turns.
- Radius API-key/OAuth capabilities and Anthropic browser/copy-code login use the
  existing official provider lifecycle and SSE interaction bridge. No parallel
  credential store or automatic Radius MCP configuration changes.

## Settings compatibility

- HTTP MCP OAuth JSON supports `authServerMetadataUrl`: HTTPS or loopback HTTP,
  without embedded URL credentials. Sensitive URL values are masked and restored
  only from the same saved server; `null` removes an optional setting.
- General settings preserve all shared CLI `quietStartup` modes: all notices,
  header only, and quiet. These do not change Web chat rendering.
- Tool permissions, opt-in activation, Chat-only/subagent isolation and explicit
  MCP save/reload/project-trust rules remain unchanged.

## Desktop and standalone runtime completeness

- Trace complete hoisted/nested `pi-codemode`, `pi-mcp`, `chord`, and
  `pi-telemetry` packages, including manifests, JS loaders, worker dependencies,
  QuickJS/Photon WASM, and runtime-referenced SDK documentation.
- New runtime-package guards reject missing manifests, missing nested packages,
  empty/truncated assets and directories masquerading as files. Desktop assembly
  compares the actual bundle against the installed source tree.
- Fix the independently reproduced missing nested Chord manifest and telemetry
  package; regression checks reject the original defective bundle.

## Verification

- 1309 tests; TypeScript, zero-warning lint and whitespace checks.
- Isolated regular and standalone builds; 19 HTTP checks on each build.
- 15 actual standalone SDK fixtures, including Codemode image generation,
  Photon conversion/resizing, MCP stdio exposure and loopback OAuth/PKCE,
  metadata override, shared token storage and logout.
- Six public runtime packages successfully imported from the standalone bundle;
  OAuth, runtime-package, worker, WASM and documentation guards passed.
- Feature fixtures use temporary configuration and synthetic/local providers,
  not production credentials or paid model calls.

Node.js 22.19.0 or newer is required. The existing export-route dynamic-import
build warning is unchanged. Browser/WebView and real-provider OAuth certification
remain outside these fixtures; stdio MCP dependencies need to be installed on
its server's PATH.
