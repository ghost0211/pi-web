# Pi Web v0.9.42

## Upgrade the embedded Pi SDK to 1.1.0

- Upgrade all four direct SDK packages together from 1.0.4 to 1.1.0, with matching
  official runtime packages in the lockfile. This changes Web's embedded kernel;
  updating the global Pi CLI alone does not update the desktop application's SDK.
- Obtain Haiku 5.5, supported thinking levels, image-capable classifiers, native
  llama.cpp decision models and upstream runtime fixes through the official SDK.
  Chat and classifier operations remain separate even when they share a model ID.
- Use upstream prompt-length pricing corrections for newly recorded usage;
  historical session costs are not recalculated. Preserve valid base-rate plus
  tiered model pricing configurations.
- Keep the Node.js minimum and bundled sidecar at 22.19.0.

## Cancellation and tool duration

- Distinguish a cancelled `agent_settled` from normal completion. Preserve UI
  settlement, history reload and idle cleanup while suppressing successful-run
  notifications and completion sounds for cancelled work.
- Prefer the SDK's recorded `durationMs` for completed tool duration, including
  zero. Legacy results still fall back to the timestamp-based estimate.
- Add offline regressions for cancellation, successful subsequent runs, accurate
  tool duration, new model operations and tiered pricing.

## Verification and desktop delivery

- Local verification passes: 217 targeted regressions (including real compiled
  NSIS installation/rollback), 5 Rust shell tests, type checking and zero-warning
  lint. Full Web regressions run on Ubuntu CI; Windows keeps branch typecheck/lint and
  runs Rust shell plus mandatory compiled NSIS installation/rollback checks in
  the desktop workflow.
- Retain the v0.9.41 staged `server/` and `node/` replacement fix, preventing old
  nested SDK packages from surviving an upgrade and shadowing the new kernel.
- Synchronize npm/Cargo manifests and lockfiles to 0.9.42. Release a fresh signed
  Windows installer and updater manifest under immutable tag `desktop-v0.9.42`.
- Do not alter user sessions, credentials, local CLI installations or settings.
