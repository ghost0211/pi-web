  the shared `config-input` control treatment: visible border, panel background,
  hover feedback, focus ring and pointer cursor, so they read as editable
  controls instead of plain description text.
- Add regressions pinning the control styling hooks; existing Codemode save /
  reload-boundary behavior is unchanged.

  compiled NSIS installation/rollback checks.
- Synchronize npm/Cargo manifests and lockfiles to 0.9.43. Release a fresh signed
  Windows installer and updater manifest under immutable tag `desktop-v0.9.43`.
- Carry over the v0.9.42 Pi SDK 1.1.0 kernel and the v0.9.41 staged installer
