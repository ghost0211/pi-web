# Pi Web v0.9.44

## Per-provider icons in the model selector

- Show each provider's icon in the composer model pill and in dropdown option
  rows at a uniform 14px size, reusing the existing provider icon sprite
  already used by the models configuration panel.
- Resolve provider ids with exact match, then a stripped `custom-` prefix, then
  the longest separator-bounded vendor suffix, so user-defined providers such
  as `custom-openai` or `my-team-deepseek` inherit the vendor icon. Providers
  that match nothing keep the previous generic chip icon.

## Verification and desktop delivery

- Local verification passes: 33 targeted selector/icon regressions, type
  checking and zero-warning lint. Full Web regressions run on Ubuntu CI; the
  desktop workflow keeps Windows Rust shell tests and mandatory compiled NSIS
  installation/rollback checks.
- Synchronize npm/Cargo manifests and lockfiles to 0.9.44. Release a fresh signed
  Windows installer and updater manifest under immutable tag `desktop-v0.9.44`.
- Carry over the v0.9.42 Pi SDK 1.1.0 kernel, the v0.9.41 staged installer
  payload replacement and the v0.9.43 Codemode control styling; do not alter
  user sessions, credentials, local CLI installations or settings.
