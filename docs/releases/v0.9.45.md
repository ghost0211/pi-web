# Pi Web v0.9.45

## Codex-style session sidebar

- Project rows reveal the new-session and options buttons on hover (always
  visible on touch devices), and right-clicking a project name opens a context
  menu with new session here, copy path, hide project and remove permanently.
  The legacy "..." dropdown opens the same menu.
- Session rows show pin and archive actions on hover; rename and hide moved
  into the new right-click context menu. The desktop shell's external
  `session-row-contextmenu` listener keeps first claim on the menu.
- Pinned sessions carry a pin marker and sort before unpinned families inside
  their project group. Archiving clears the pin.
- Archived sessions leave the default list without touching any data; the
  section "..." menu's "show archived sessions" toggle lists them again for
  quick unarchiving. Pin/archive state is browser-local, like hidden sessions.
- Shared viewport-aware context menu component with outside-click, Escape,
  scroll and resize dismissal; zh-CN, zh-TW and en translations.
