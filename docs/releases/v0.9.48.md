# Pi Desktop / Pi Web v0.9.48

## Per-session quota fallback model

- Add an optional backup model that is stored per conversation and defaults to
  off. Configure it from the composer's model picker through the new
  **Primary** / **Quota backup** tabs; a `↪` marker shows when a backup is set.
- Configuring a backup never changes the active or default primary model.
  Automatic failover activates the backup for the current session only.
- The backup must differ from the primary model. Forked and cloned sessions
  carry the current configuration; temporary rebuilds and tool-preset changes
  preserve it. Legacy sessions without configuration stay off.
- A browser preference only initializes fresh composers. Existing sessions
  always trust their own persisted configuration.
- Explain the quota-only trigger and cross-provider cost warning in all three
  bundled locales.

## Conservative server-side failover

- When the primary model definitively reports quota exhaustion, switch the
  current run to the backup at the SDK settlement boundary and continue it once.
  The client never resends the prompt, and completed tool calls are not replayed.
  Only the failed assistant reply is excluded from model context; the user
  message, history, and tool results remain.
- Match only explicit, documented quota signals from OpenAI, Anthropic,
  DeepSeek, MiniMax, and OpenRouter. Generic `429`/rate-limit responses,
  network and authentication failures, `5xx` errors, Google's generic
  `RESOURCE_EXHAUSTED` wording, and OpenRouter in-flight budget exhaustion do
  not trigger a fallback.
- Revalidate the backup against the current visible model scope and
  authentication, and require compatible image input, context window, and
  output room before switching. Google SDK adapters are never forced onto a
  custom fetch.
- Persist a bounded audit entry with `from`, `to`, `ruleId`, `kind`, and
  `timestamp`, and emit a localized warning as soon as the switch happens.
  Raw upstream response bodies, request headers, API keys, and prompts are
  never persisted. Raw Codex error evidence is request-isolated, size-bounded,
  and invalidated by a successful request. Fallback notices are read from the
  active branch only.

- Focused fallback, quota-classifier, RPC, session, composer, and adjacent
  regression suites: **151 tests passed**. TypeScript, repository-wide
  zero-warning ESLint, and `git diff --check` pass. No real provider calls,
  sessions, or credentials were used.

  requires real compiled NSIS upgrade and rollback checks before publication.
- Publish a fresh signed installer, detached signature, and
  `desktop-latest.json` under immutable tag `desktop-v0.9.48`, keeping the
  embedded Pi SDK at 1.1.0. The release becomes latest only after every signed
  asset has uploaded.
