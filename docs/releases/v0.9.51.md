# Pi Desktop / Pi Web v0.9.51

## Compact thinking-level picker

- Replace the two primary/backup thinking buttons with one **Thinking: high**
  toolbar entry. Its popup has **Primary** and **Backup** tabs, reducing
  composer crowding without combining the two model preferences.
- The toolbar always summarizes the active primary model's level. Switching
  tabs does not write either preference, and editing backup thinking does not
  change primary thinking. Each tab retains its model-specific supported levels
  and provider-native labels while sending canonical SDK levels.
- Without a configured backup, the Backup tab remains visible but gray and
  disabled. Missing capability metadata and models with no adjustable thinking
  disable only their own tab; the picker stays usable if the other model is
  editable. Streaming, compaction and model switches disable the whole picker.
- Changing either model or entering a busy state immediately closes an open
  panel. Read-only views continue to omit editing controls. Per-session backup
  persistence and quota failover behavior are unchanged.

## Mobile and keyboard behavior

- Keep mobile label folding and clamp the popup to viewport edges. Choose the
  roomier side of the trigger and cap the scrollable panel height, including
  visual-viewport changes, so narrow screens do not clip the thinking options.
- Outside pointer interaction closes the popup for both mouse and touch.
- Add linked tab/panel IDs, arrow-key and Home/End navigation for tabs and
  options, and focus return when selecting a level or pressing Escape.
- Provide matching labels in English, Simplified Chinese and Traditional
  Chinese.

## Verification and delivery

- Browser checks used the real React composer with isolated fixed test data:
  one toolbar entry, independent backup edits, disabled unconfigured backup,
  busy-state closure, 390 px and 320 px mobile layouts, and a short viewport.
  No real model requests or user-session changes were made.
- Full local suite: **1705 tests, 1673 passed, 28 skipped, 4 failed**. The four
  failures remain the existing Windows `EPERM` limitation in MCP symlink
  fixtures; the assertions cannot run locally. The release workflow runs the
  full Web suite on Linux before building the installer.
- TypeScript, repository-wide zero-warning ESLint, and `git diff --check` pass.
- Publish the signed installer, detached updater signature and
  `desktop-latest.json` under immutable tag `desktop-v0.9.51`. The release
  becomes latest only after all three assets upload. Pi SDK remains 1.1.0;
  this release changes no dependency versions.
