# Pi Desktop / Pi Web v0.9.52

## Quota fallback now restores the configured primary model

- Automatic quota fallback is temporary execution, not a selection change. The
  exact primary model and thinking level are checkpointed into a durable
  `pi-web:primary-model-snapshot` entry **before** `setModel(backup)` can
  persist a `model_change`, and both are restored when the logical run
  settles — on success, error, cancellation or Stop.
- Reopening a session with a pending checkpoint repairs it before accepting
  new work (including unambiguous pre-checkpoint sessions from v0.9.49–51).
  If the configured primary is unavailable, the session fails closed instead
  of silently continuing on the backup.
- Model and thinking controls always show the configured primary; the
  context-usage ring follows the actual execution model. Session detail,
  context and `get_state` APIs expose `primaryModel` separately from the
  runtime model, and historical answers keep their backup attribution.
- Choosing a model or thinking level explicitly supersedes a pending restore;
  busy sessions reject configuration edits, and prompt/steer/follow-up
  commands wait for in-flight restoration so no request can run on the backup
  by accident.

## Fallback warnings no longer replay from history

- The persisted audit notice is a history baseline: switching back to a
  recovered session, reloading the page or polling state no longer re-opens
  the old fallback toast.
- A genuinely new fallback during an active run still warns exactly once —
  including when the live SSE event was missed and state reconciliation
  catches up mid-run.

## Verification and delivery

- Full local suite: **1739 tests, 1707 passed, 28 skipped, 4 failed**. The
  four failures remain the existing Windows `EPERM` limitation in MCP symlink
  fixtures; the release workflow runs the full Web suite on Linux where they
  pass.
- Real React composer fixtures verified in a browser: the primary model and
  thinking level stay stable during an active fallback, across a mid-fallback
  reload, and after settlement; repeated revisits stay silent while a new
  fallback warns once. No live model calls were used.
- TypeScript, repository-wide zero-warning ESLint, and `git diff --check`
  pass.
- Publish the signed installer, detached updater signature and
  `desktop-latest.json` under immutable tag `desktop-v0.9.52`. The release
  becomes latest only after all three assets upload. Pi SDK remains 1.1.0;
  this release changes no dependency versions.
