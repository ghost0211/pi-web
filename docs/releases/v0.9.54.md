# Pi Desktop / Pi Web v0.9.54

## Desktop update controls move into the app card

- Remove the separate "Desktop update" section. Its buttons now sit at the
  left edge of the Pi Desktop hero card, and the update state renders as a
  parenthesized label immediately before the version badge — for example
  **Pi Desktop (已是最新版本) v0.9.54**.
- Everything except the placement is unchanged: the update check still runs
  when the panel opens, the button re-checks on demand, installing still asks
  for confirmation, download progress and the install phase still replace the
  status label, and failures still appear inline in the same card.
- When a newer release is found its release notes appear under the card, and
  the install button appears next to the check button. Browsers (non-desktop)
  still show neither the controls nor the desktop status label.
- Narrow and mobile layouts stay readable: the controls wrap, the identity
  block keeps a minimum width, and long notes or errors wrap instead of
  overflowing the card.

## Verification and delivery

- New About component tests cover the merged layout, auto-check, manual
  re-check, browser behavior, checking/error states, confirmation, download
  progress, install phase, retry after failure, cancellation and all three
  locale labels. A real React fixture was additionally checked in a browser at
  desktop, 390px and 320px widths with no horizontal overflow; the mock
  installer never downloads a real payload.
- Full local suite: **1750 tests, 1718 passed, 28 skipped, 4 failed**. The four
  failures remain the existing Windows `EPERM` limitation in MCP symlink
  fixtures; the release workflow runs the full Web suite on Linux where they
  pass.
- TypeScript, repository-wide zero-warning ESLint, and `git diff --check`
  pass.
- Publish the signed installer, detached updater signature and
  `desktop-latest.json` under immutable tag `desktop-v0.9.54`. The release
  becomes latest only after all three assets upload. Pi SDK remains 1.1.0;
  this release changes no dependency versions.
