# Pi Desktop / Pi Web v0.9.56

## 手机界面（Mobile web）

- The mobile header now prioritizes the current session title. Cumulative
  statistics move into a compact button that opens the existing details panel,
  while high context-usage warnings remain visible.
- Header actions use a labelled grid instead of a crowded icon-only row:
  two columns at 360px and below, three on larger phones. Escape restores
  focus to the trigger, and outside clicks close the grid.
- Mobile session rows show a single **…** menu rather than permanent
  pin/archive buttons, leaving more room for titles. It reuses the existing
  context-menu actions and permission/busy guards without selecting the
  session or changing the virtual list's fixed row height. Desktop hover
  actions remain unchanged.
- Phone drawers are wider and have a stronger backdrop and larger touch
  targets. The composer gets a 44px more-controls button, a separate secondary
  controls row and bottom safe-area padding. Model and auto-advance dialogs
  remain usable without accidentally closing the composer controls.

## 当前模型同步（Current-model synchronization）

- Returning to an idle chat after its SSE grace period now refreshes the
  configured primary model on foreground, online and page-restoration events.
  Visible idle polling observes live wrappers; wake-up and dispatch can also
  read a dormant session without starting a wrapper or replacing chat history.
- Assistant/context-usage reads now apply model metadata as well as usage.
  Prompt dispatch starts a nonblocking model read, not an implicit `set_model`
  or a prompt replay. Observation reads time out after five seconds and keep
  the last confirmed selection when offline.
- Model-only request watermarks, session/run checks and manual-switch
  barriers prevent delayed snapshots from overwriting newer choices, even
  when usage is missing. Primary/backup thinking preferences stay independent.
- Historical answers retain their actual generating model. A temporary quota
  fallback affects execution and the context ring, never the configured
  primary selection. Existing quota-only fallback and startup policies are
  unchanged.

## Verification and delivery

- **142 focused tests passed**. Full local suite: **1880 tests, 1848 passed,
  28 skipped, 4 failed**. The four failures remain the existing Windows
  `EPERM` limitation in MCP symlink fixtures; the release workflow runs the
  complete Web suite on Linux.
- TypeScript, repository-wide zero-warning ESLint and `git diff --check` pass.
- Real React browser fixtures with mocked HTTP/navigation passed at
  **320/360/390/412/640px in zh-CN/en/zh-TW**, including menus, focus restoration,
  model portals, no horizontal overflow, live/dormant cross-window model
  updates, a reduced-height viewport and an unchanged desktop header.
  Physical-phone keyboard/safe-area behavior and installed-desktop operation
  remain manual validation items; no live provider billing was exercised.
- The signed installer, detached updater signature and `desktop-latest.json`
  are delivered under immutable tag **desktop-v0.9.56**. The release becomes
  latest only after all three assets upload. Dependency versions are unchanged;
  Pi SDK remains 1.1.0.
