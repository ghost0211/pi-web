# Pi Desktop / Pi Web v0.9.60

## Usage dashboard: fixed summary, dropdown details

Two usability fixes for the **用量与成本 / Usage & Cost** dashboard introduced in
v0.9.59.

- **Scrolling no longer moves the overview.** The panel is split into a fixed
  block — title, time filters, notices, the four summary cards and the token
  trend chart — and a scrollable detail area below it. A wheel scroll inside the
  panel now only moves the detail list, so the numbers you are comparing stay on
  screen while you browse the breakdown. The trend chart's height is clamped for
  short viewports so it cannot squeeze the detail area away.
- **By provider / by project are now dropdowns.** Instead of expanding every
  provider and project (which pushed the interesting rows off screen), each
  grouping is a single selector whose options carry the label together with its
  tokens and cost, for example `zenmux · 1.49M · $6.52`. Only the selected entry
  is rendered underneath, with its share bar, token breakdown and nested model
  list. The selection defaults to the top (highest-cost) entry and automatically
  falls back to it when a period change removes the previous choice, so the
  detail area is never left empty.

## Verification and delivery

- Full local suite: **1934 tests, 1902 passed, 28 skipped, 4 failed**. The four
  failures remain the existing Windows `EPERM` limitation in MCP symlink
  fixtures; release CI runs the complete Web suite on Linux.
- TypeScript, repository-wide zero-warning ESLint and `git diff --check` pass.
- New panel coverage: the filter bar, cards and chart must live outside the
  scroll container (and in that order); both groupings must render a dropdown
  while only the selected entry gets a detail block; and the selection must fall
  back to the top entry when the current one disappears from the response.
- Real React browser verification: after scrolling the detail area to a
  non-zero offset, the filter bar, cards and chart keep pixel-identical
  positions; switching the provider dropdown swaps the provider detail and its
  share bar exactly, and switching the project dropdown does the same
  independently.
- The signed installer, detached updater signature and `desktop-latest.json`
  are delivered under immutable tag **desktop-v0.9.60**. The release becomes
  latest only after all three assets upload.
