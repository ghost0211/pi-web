# Pi Desktop / Pi Web v0.9.61

## Usage dashboard: provider/project tabs and full-height layout

Follow-up polish for the **用量与成本 / Usage & Cost** dashboard.

- **One breakdown at a time.** The two groupings are now mutually exclusive
  tabs — **按供应商 / By provider** and **按项目 / By project** — instead of two
  stacked sections. Switching tabs keeps each tab's own dropdown selection, so
  you can compare a provider and a project without losing either choice.
- **`all` restores the full list in both dropdowns.** Each dropdown starts at
  `all` and can go back to it at any time. The value is an empty sentinel rather
  than the literal string, so a provider or project genuinely named `all`
  remains separately selectable and is never confused with "show everything".
  A selection that disappears from a new response resets to `all` permanently,
  so widening the date range cannot silently revive a filter the UI had already
  stopped showing.
- **The panel fills the settings window.** The panel used to cap itself at
  `min(600px, 75dvh)` even when the settings dialog was taller, which left the
  bottom of the page empty and squeezed the detail list. Embedded in Settings it
  now fills the available height, so every spare pixel goes to the breakdown;
  the title, time filters, summary cards, trend chart and the tab row stay fixed
  while only the detail cards scroll. Short sections compact their spacing
  instead of hiding any summary value or the chart.
- **Accessible tabs.** The tab strip is a real `tablist` with arrow/Home/End
  navigation, a roving tab index and a single dynamic `tabpanel` that both tabs
  reference; switching a tab returns the detail list to the top.

## Desktop: shortcut named `pi`, startup page says Pi Desktop

- **The Windows desktop shortcut is now `pi`** instead of `Pi Web Desktop`.
  Install and update hooks rename an existing shortcut in place, so its target,
  arguments, working directory and pin state survive; a shortcut owned by a
  different application is never touched, and if the name is already taken by
  something else the installer keeps both shortcuts as they are. Because the
  interactive installer creates its desktop shortcut on the finish page — after
  the post-install hook — the migration also runs at GUI exit, and never after a
  failed installation.
- **A real uninstall removes only its own link.** `/UPDATE` leaves the shortcut
  alone; a normal uninstall deletes `pi.lnk` (and unpins it) only when it still
  points at this installation.
- **The startup waiting page** now reads **Pi Desktop** in both the window title
  and the "Starting Pi Desktop…" heading.
- The installer identity is unchanged on purpose: the `productName`
  (`Pi Web Desktop`), start-menu entry, install directory, application
  identifier and the updater asset names all stay the same, so a newer installer
  still upgrades an existing installation in place.

  real NSIS toolchain, against an isolated temporary desktop directory).

  and uninstall with and without `/UPDATE`.

  while the details scroll.

- The signed installer, detached updater signature and `desktop-latest.json` are
  delivered under the immutable tag **desktop-v0.9.61**. The release becomes
