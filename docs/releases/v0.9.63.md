# v0.9.63

## 升级 Pi SDK 至 1.3.0

嵌入的 SDK（`pi-coding-agent` / `pi-ai` / `pi-agent-core` / `pi-tui`，传递依赖 `pi-mcp` / `pi-codemode`）升级到 1.3.0。接口层面对 pi-web **零破坏**（详见 `docs/pi-sdk-1.3.0-adaptation.md` 的逐项审计），行为改进自动生效：

- **压缩/摘要更抗抖动**：网关 `Unable to forward upstream stream` 和 `The service is temporarily unavailable` 错误现在会自动重试，压缩摘要不再一次失败就放弃。
- **gpt-6.1-sol 上下文窗口修正为 500K**（原 272K）。
- **换模型更干净**：旧模型的思考块不再被当成正文发给新模型。
- **恢复会话时还原会话内激活的工具负载**；pi-web 的工具预设仍在其后应用，优先级不变。
- **模型范围歧义提示**：同一模型 id 被多个 provider 提供时全部列出并给出警告，不再按目录顺序静默挑一个；精确模式的歧义仍按 pi-web 的严格规则直接报错。
- 工具参数 malformed JSON 直接校验失败并反馈原文；非法 `\u` 转义不再静默丢字段。
- Anthropic/Bedrock 错误工具结果带图 400、Gemini 4 Argon 思考预算、小米 MiMo / Claude Haiku 5.5 / Opus 5 思考档位等供应商修复。
- 上游内部依赖改为精确锁定，桌面打包依赖图更稳定。

### 验证

- 全量 1961 测试：1929 通过 / 28 跳过 / 仅 4 个失败（已知 Windows EPERM 符号链接用例，与本次无关）；tsc / lint 干净。
- 新增 `lib/pi-sdk-1.3.test.mjs`：锁定 1.3.0 的范围歧义行为（glob 全部列出且无警告、模糊匹配附歧义警告、精确歧义仍由 pi-web 拦截）。
