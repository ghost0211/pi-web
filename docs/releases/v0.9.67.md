# v0.9.67

## 1. 结构化交付物：让「本轮成果」显示你真正要的文件

以前成果卡片只能从回答文字和 write/edit 调用里**推断**产物，无法区分「最终交付的 SQL」和「生成它的 Python 脚本」。现在模型会主动声明交付物：

- 新增 `present_files` 工具（仅模型可调用）。模型给出路径 + 说明，服务端**只读探测**（存在性、大小、类型），返回带版本标记的结构化结果。
- 卡片把交付物排在最上面，辅助脚本归入下方「其他改动的文件」；同一文件不会重复出现。
- 安全：每个路径必须同时通过词法白名单与 realpath 白名单，越权路径、符号链接逃逸一律拒绝；工具不读文件内容、不执行 HTML、不自动弹窗；伪造或全缺失的声明直接判失败。
- 旧的「从回答里猜路径 + 校验修改时间」仍作为兜底保留。

## 2. 结构化问卷：一次问清关键口径

- 新增 `ask_user_question` 工具（仅模型可调用）：一次最多 4 题，每题 2–6 个具体选项，支持推荐标记、多选、自填，以及选项的 Markdown 预览。
- 答案作为普通工具结果回到同一轮，不额外增加模型回合；用户取消会被如实报告为「拒绝」，不会默认选中任何选项。
- 复用现有扩展交互通道，因此刷新页面可恢复、停止运行会正常结束、自动推进会暂停。
- 题目与答案共用同一套严格校验（数量、选项范围、重复标签、预览总预算、答案不得混用类型）。

## 3. 长会话性能

- 流式回答状态移出 React 状态：聊天窗口只订阅「是否在流式 / 是否有内容」，流式气泡与右侧轨道各自订阅自己渲染的部分。一个 chunk 现在只重渲染一个气泡，而不是整页聊天。
- 提示锚点的高度测量改为直接订阅流式状态，不再进入 React 更新周期。
- 会话列表扫描：文件仅追加增长且 inode、头部与边界样本一致时，从上次位置续扫；截断、替换或重写则回退全量读取。**已知限制**：同 inode、同大小、同修改时间且边界样本未变的就地改写无法被采样发现。

## 4. 主代理 / 子代理成本明细

Agent 切换器现在显示每个代理的「耗时 · tokens · 费用」，并在标题下方给出一行家族合计：

- 费用只累加历史记录中的 `usage.cost.total`，**绝不按当前价目重算**；没有任何费用记录的会话标记为「部分缺失」，而不是当成 0。
- 耗时优先采用精确的 `pi-web:run-timing` 记录，早期只有估算的轮次以 `~` 标注；子代理可并行，因此合计是累计执行时间而非自然耗时。
- 批量统计接口有 id 校验、32 条上限、请求体积上限，响应不含路径或正文；只在面板打开且家族运行中、页面可见时轮询。

## 5. 运行中的任务药丸改为边缘光环

后台 Bash / 子代理 / 任务进度三个药丸在运行时会追加绿点并撑宽，在手机上导致整行错位。现在改为药丸内侧的呼吸绿环：不占布局空间、不被横向滚动容器裁切，可见文字保持不变，运行状态移到无障碍标签与悬浮提示；进度数字使用等宽数字；「减少动态效果」下保留静态绿环。

## 验证

- 全量 2048 测试：2016 通过 / 28 跳过 / 仅 4 个已知 EPERM（Windows 符号链接）；tsc 与 lint 干净。
- 浏览器实测（1440 与 390 两档、浅色与深色）：交付物置顶且不重复、长文件名不溢出、点击不选中文字、打开与 Diff 回调正确；问卷单选互斥、自填与选项互斥、空自填禁用提交、预览渲染、提交载荷与取消结果正确；代理面板逐行与合计数字、`~` 估算与「部分缺失」标记、标题行不再换行错乱；药丸在空闲/运行/停止之间切换时几何完全不变。
