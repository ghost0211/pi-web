# v0.9.73

> 在 Windows 之外补发 Linux 桌面端（AppImage + deb），自动更新清单同时携带两个平台。

## 新增：Linux 桌面端

- CI 新增 `build-linux`（ubuntu-latest）：安装 WebKitGTK 依赖后执行 `tauri build`，产出
  - `Pi Web Desktop_<version>_x86_64.AppImage`（免安装）+ `.sig`
  - `Pi Web Desktop_<version>_amd64.deb`
- 发布新增 `publish-release`：等 `build-windows` 与 `build-linux` 都完成后，把
  Windows NSIS、Linux AppImage/deb 与合并后的 `desktop-latest.json` 一起上传，
  杜绝只发半套平台的更新。

## 改动

- **`scripts/build-desktop-server.mjs`**：内置 Node 运行时按当前平台下载
  （`node.exe` / `bin/node`），不再写死 Windows；POSIX 平台拷贝后补可执行位。
  新增 `PI_DESKTOP_ONLY_NODE_RUNTIME=1` 与 `PI_DESKTOP_SKIP_NODE_COPY=1` 便于探针单独验证下载/解压。
- **`src-tauri/tauri.conf.json`**：`targets` 增加 `appimage`、`deb`；新增
  `bundle.linux`（Development 分类、deb 依赖声明、AppImage 媒体框架）；
  长描述改为跨平台表述。
- **`scripts/create-desktop-update-manifest.mjs`**：从指定 bundle 目录收集
  `windows-x86_64`（NSIS）与 `linux-x86_64`（AppImage）的签名产物，生成多平台
  `desktop-latest.json`；`.deb` 只发布不进更新清单。
- **`src-tauri/src/main.rs`**：无需改动，已有 `cfg!` 分支（spawn、kill、打开文件、设置权限）。

## 验证

- Windows 本地：`tsc`/`lint` 干净；桌面相关测试 37/37（新增 4 项：
  Node 跨平台下载契约、tauri 双平台 targets、CI 双 job + 合并发布、多平台 manifest）。
- Linux（WSL Ubuntu 22.04）：`PI_DESKTOP_ONLY_NODE_RUNTIME=1` 跑通
  `node-v22.19.0-linux-x64.tar.xz` 的下载、SHA-256 校验与解压；`bin/node -v` 正常。
- Windows Node 下载路径回归通过（`node.exe` 93.9 MiB）。

## 发布条件

以 GitHub Actions 为准：`desktop-windows` 工作流需 `build-windows` 与
`build-linux` 均成功，且 `publish-release` 产出
`Pi.Web.Desktop_<version>_x86_64.AppImage` 与合并后的 `desktop-latest.json`。
