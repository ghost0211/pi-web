# v0.9.74

## 修复
- **Linux 桌面端构建**：`tauri.conf.json` 的 `bundle.linux` 多了 Tauri 不认识的
  `category` 字段，导致 Rust 构建脚本 `exit 101`，v0.9.73 的 Linux/Windows
  打包都被跳过。已移除并补测试（只允许 `appimage`/`deb`/`rpm`）。

## 新增
- **Linux 桌面端**：CI 新增 `build-linux`，产出 `x86_64.AppImage`（免安装）与
  `amd64.deb`；`desktop-latest.json` 同时携带 `windows-x86_64` 与 `linux-x86_64`。
- **定时发送**：输入框「工具」菜单新增「定时发送…」，选择未来时间（精确到分钟）
  与内容，到点自动发送（空闲即发 / 运行中则作为后续消息排队），可取消。
- **工具菜单**：「自动推进」改为「工具」下拉菜单，内含「自动推进…」与「定时发送…」。
- **项目置顶**：项目右键/「⋯」菜单新增「置顶项目」，置顶项目排在侧栏最前并显示图钉。
- **移动端模型可见**：空闲时模型 chip 直接显示在输入框（图标+名称，可点选），
  不再全藏进「⋯」。

## 验证
- Windows 本地：tsc/lint 干净；全量 2084/2052/4 EPERM/28 skip（4 个失败为历史遗留
  Windows MCP symlink EPERM，与本次无关）。
- `cargo test`（Rust 外壳）10/10 通过。
- Linux Node 运行时下载/校验/解压已在 WSL 验证。

## 发布条件
`desktop-windows` 工作流需 `test`、`build-windows`、`build-linux` 均成功，
`publish-release` 产出 Windows NSIS、Linux AppImage/deb 与合并的 `desktop-latest.json`。
