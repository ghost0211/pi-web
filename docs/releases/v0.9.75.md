# v0.9.75

## 修复
- **Linux 桌面端构建（tauri.conf）**：`bundle.linux` 多了 Tauri 不认识的
  `category` 字段，导致 Rust 构建脚本 `exit 101`。已移除并补测试。
- **Linux 桌面端打包（资源符号链接）**：`resources: ["server/", "node/"]` 递归打包整个
  Node 目录，但 POSIX Node 发行版的 `node/bin/npm`、`npx`、`corepack` 是指向
  `../lib/node_modules/...` 的符号链接，Tauri 资源展开器报
  `resource path 'node/bin/corepack' doesn't exist` 并使 `build-linux` 失败。现在
  `build-desktop-server.mjs` 在构建时逐文件枚举 server 与 node 负载（跟随符号链接、展开为
  实体文件清单）写进 `bundle.resources`，Linux 与 Windows 打包都能通过。

## 新增（相对 v0.9.73）
- **Linux 桌面端**：CI `build-linux` 产出 `x86_64.AppImage`（免安装）与 `amd64.deb`；
  `desktop-latest.json` 同时携带 `windows-x86_64` 与 `linux-x86_64`。
- **定时发送**：输入框「工具」菜单新增「定时发送…」，选择未来时间（精确到分钟）与内容，
  到点自动发送（空闲即发 / 运行中则作为后续消息排队），可取消。
- **工具菜单**：「自动推进」改为「工具」下拉菜单，内含「自动推进…」与「定时发送…」。
- **项目置顶**：项目右键/「⋯」菜单新增「置顶项目」，置顶项目排在侧栏最前并显示图钉。
- **移动端模型可见**：空闲时模型 chip 直接显示在输入框（图标+名称，可点选）。

## 验证
- Windows 本地：tsc/lint 干净；全量 2085/2053/4 EPERM/28 skip（4 个失败为历史遗留
  Windows MCP symlink EPERM，与本次无关）。
- `cargo test`（Rust 外壳）10/10 通过。
- Linux 资源清单已在 WSL 验证：`node/bin` 的 `node`/`npm`/`corepack` 等符号链接全部
  正确展开为实体文件，`missing=0`。

## 发布条件
`desktop-windows` 工作流需 `test`、`build-windows`、`build-linux` 均成功，
`publish-release` 产出 Windows NSIS、Linux AppImage/deb 与合并的 `desktop-latest.json`。
