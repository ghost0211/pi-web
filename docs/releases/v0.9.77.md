# v0.9.77

## 修复（Linux 打包诊断）
- **v0.9.76 的 `build-linux` 进入 AppImage 阶段**（Rust 编译 + 资源打包已通过，
  `node/bin` 符号链接已物化），但在运行 `linuxdeploy` 时失败：`failed to run linuxdeploy`，
  且 Tauri 吞掉了它的 stderr。产物路径 `Pi Web Desktop_0.9.77_amd64.AppImage` 带空格，
  是可疑点。
- 本版把 Windows 与 Linux 的打包都加上 `--verbose`，并在 Linux 构建失败时跑一个独立的
  **linuxdeploy 诊断步骤**（对最小 AppDir 直接调 linuxdeploy 并打印 stderr），
  以便拿到真实失败原因后做针对性修复。

## 说明
此版本主要用于**诊断**，不改变产品行为。其余功能同 v0.9.76。
