# v0.9.78

## 修复
- **Linux AppImage 打包**：诊断步骤暴露出真实错误 ——
  `Could not find dependency: libc.musl-x86_64.so.1`。server bundle 里的
  `@img/sharp-linuxmusl-x64` 是 musl libc 的原生模块（Alpine 用），在 Ubuntu（glibc）
  构建机上 linuxdeploy 无法解析，导致 AppImage 失败。现在 `build-desktop-server.mjs` 在打包前
  调用 `pruneForeignNativeModules()`，从 server 的 `node_modules/@img` 里**裁掉与目标平台不符的
  sharp 原生包**（musl 版、其它平台的 win32/darwin 版），只保留当前平台的 glibc 版。
  同时减少安装体积。

其余同 v0.9.76/77（符号链接物化、verbose + linuxdeploy 诊断、Linux 打包管线、
定时发送、工具菜单、项目置顶、移动端模型可见）。
