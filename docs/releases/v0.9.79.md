# v0.9.79

首个同时发布 Windows 与 Linux 安装包的版本。

## 平台
- **Windows**：`Pi Web Desktop_0.9.79_x64-setup.exe`（NSIS，含签名）。
- **Linux**：`Pi Web Desktop_0.9.79_amd64.AppImage`（免安装，含签名）与
  `Pi Web Desktop_0.9.79_amd64.deb`（apt/dpkg 安装）。更新清单 `desktop-latest.json`
  同时携带 `windows-x86_64` 与 `linux-x86_64`。
- macOS 暂未发布（需要 macOS 构建机与 Apple 签名）。

## 功能（相对 v0.9.72）
- **Linux 桌面端**：新增 AppImage / deb 安装包与自动更新。
- **定时发送**：输入框「工具」菜单新增「定时发送…」，选择未来时间（精确到分钟）与内容，
  到点自动发送（空闲即发 / 运行中则作为后续消息排队），可取消。
- **工具菜单**：「自动推进」改为「工具」下拉菜单，内含「自动推进…」与「定时发送…」。
- **项目置顶**：项目右键/「⋯」菜单新增「置顶项目」，置顶项目排在侧栏最前并显示图钉。
- **移动端模型可见**：空闲时模型 chip 直接显示在输入框（图标+名称，可点选）。

## 本次发版修复的构建问题
- `bundle.linux` 的 `category` 字段导致 Rust 构建失败 → 已移除。
- Linux Node 运行时的 `bin/npm`/`npx`/`corepack` 符号链接让 Tauri 资源展开失败 →
  打包时物化为实体文件，并逐文件枚举资源清单。
- server bundle 里的 `@img/sharp-linuxmusl-x64`（musl libc）让 linuxdeploy 无法解析
  → 打包前裁掉与目标平台不符的 sharp 原生包。
- `publish-release` 的 `.deb` glob 在发布 shell 下不展开 → 用 nullglob + 显式数组。
