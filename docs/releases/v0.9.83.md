# v0.9.83

## 更新
- **内置 Pi SDK 升级到 1.4.0**：无破坏性变更。其中 `generateSummary()`/
  `generateSummaryWithUsage()` 不再受 `reserveTokens` 固定上限限制，改用模型自身输出上限——
  修复长会话/长推理时压缩与分支摘要报「generation hit the token cap」的问题。
- **「关于」面板精简**：去掉与「全局 CLI」重复的「当前版本」卡片，
  「发现新版本」徽标移到「全局 CLI」一行上。

## 平台
- **Windows**：NSIS 安装包 + 签名。
- **Linux**：AppImage + deb + 签名（首次随正式版发布），`desktop-latest.json`
  同时携带 Windows 与 Linux。

## 功能（自 v0.9.72 起累积）
- Linux 桌面端、定时发送、工具菜单、项目置顶、移动端模型可见。
