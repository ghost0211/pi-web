# v0.9.84

## 界面
- **「关于 → Pi Agent 内核与运行时」精简**：去掉底部「更新全局 CLI」「更新内置 SDK」
  两个按钮。内置 SDK 随应用打包，不提供客户端更新（桌面端升级时整体替换）；
  `POST /api/about` 现在拒绝 `target:"local"`（400）。
- **CLI 更新内联**：「全局 CLI」一行只在检测到新版本时显示一个可点的
  「发现新版本 vX.Y.Z」小按钮，点击即更新；已是最新时仍显示普通「已是最新版本」状态。
- 「当前版本」卡片保持移除（v0.9.83）。
