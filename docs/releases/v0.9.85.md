# v0.9.85

## 修复
- **项目置顶无效**：置顶项目的 key 由旧版本写成小写盘符（`d:\proj\repo`），
  而侧栏从会话 cwd 得到的是大写盘符（`D:\proj\repo`），查找永远匹配不上，
  所以置顶不生效。现在比较前统一规范化（盘符大写 + 原生分隔符），
  旧数据自动兼容，存储格式不变。
- **运行中发送后续消息后，自己的消息不显示**：每轮结束都会从磁盘刷新历史；
  若排队的后续消息恰好在此时被投递，刷新读到的是落盘前的快照，整体覆盖时
  把刚显示的用户消息抹掉了（助手回复是流式追加，所以只剩回复可见，刷新后才出现）。
  现在会保留「已通过 SSE 投递、但磁盘尚未确认」的用户消息，快照确认后再移除，
  不重复、不影响分页。

## 界面
- 「关于 → Pi Agent 内核与运行时」去掉底部两个更新按钮；内置 SDK 不再提供客户端更新，
  「全局 CLI」仅在检测到新版本时显示可点的更新按钮（v0.9.84）。
