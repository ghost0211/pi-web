# v0.9.87

## 中文

### 移动端输入区

- 模型与思考档位独立分行展示，保留模型名称、供应商和当前档位；主要按钮触控高度至少 44px，模型选项至少 48px。
- 模型选择改用可滚动的底部面板。打开时不再自动聚焦筛选框，只有主动点击搜索才请求虚拟键盘；桌面继续保留自动聚焦搜索。
- 修复思考档位弹层被输入区裁切、点击后看似无响应的问题，保留主模型与备用模型各自独立的档位设置。
- 临时会话、上下文用量、工具动作、压缩与提示音收进“更多”，解决新会话工具预设与临时会话按钮重叠。
- 改进窄屏运行中引导、排队与停止按钮布局，补齐弹层关闭、逐层 Escape、键盘焦点约束与回焦逻辑。

### 验证与发布

- 更新移动端 PWA 布局回归断言，使其识别独立发送区域的新类名，并继续检查发送按钮位于“更多”面板之外。
- `desktop-v0.9.86` 因上述旧测试断言失败而未发布；保留原标签，本版本使用新的不可变标签重走全量 CI。
- 浏览器验证覆盖简中、繁中、英文及 320–640px 宽度；实体手机的输入法与安全区表现仍需真机确认。
- 所有生产构建、签名和发布由 GitHub Actions 执行，提供 Windows NSIS、Linux AppImage / deb 及多平台签名更新清单。

## English

### Mobile composer

- Separate readable model/thinking controls from attachment, tool-preset and send actions. Main touch targets are at least 44px tall; model options are at least 48px tall.
- Browse models in a scrollable bottom sheet without automatically focusing search or summoning the virtual keyboard. Explicit search remains available, and desktop search autofocus is preserved.
- Fix thinking menus being clipped by the composer while preserving independent primary and backup thinking preferences.
- Move temporary-session, context-usage, tool actions, compaction and sound controls into More to prevent overlapping new-session controls.
- Improve narrow-screen streaming actions, nested Escape dismissal, focus trapping/restoration and visual-viewport resizing.

### Validation and delivery

- Update the mobile PWA regression to recognize the new independent send-action class while retaining the assertion that sending stays outside the More popover.
- The obsolete assertion prevented `desktop-v0.9.86` from being published. Its tag is retained; this release uses a new immutable tag and reruns full CI.
- Browser checks covered English, Simplified Chinese and Traditional Chinese at 320–640px widths. Physical-device keyboard and safe-area behavior still requires manual verification.
- Windows and Linux artifacts and the signed multi-platform updater manifest are built and published by GitHub Actions, without a local production build.
