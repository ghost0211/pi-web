# v0.9.88

## 中文

### 手机端新会话与输入区

- 新会话不再把大标题、空状态提示和输入框整体居中；欢迎内容保持简洁，输入区靠下停靠，更适合单手操作。
- 去掉重复的“还没有消息”提示，保留输入框内的操作引导。
- 模型选择独占整行，思考档位、附件、工具预设、“更多”和发送位于下一次级行；窄屏自然换行，保留至少 44px 的触控目标。
- 桌面端继续保留原有居中欢迎页与输入区布局。

### 桌面更新修复

- 修复 Linux AppImage 实际使用 `amd64` 文件名时，更新清单生成脚本只识别 `x86_64`、导致 Linux 更新条目缺失的问题。
- `desktop-v0.9.87` 的安装包和签名均已发布，但其更新清单缺少 Linux 条目；本版本生成同时包含 Windows 与 Linux 签名条目的新清单。
- 发布流水线现在会在生成清单后验证两个平台及签名 URL，缺少任一平台都会停止发布。

## English

### Mobile new session and composer

- Replace the vertically centered phone welcome block with a quiet welcome and a bottom-docked composer that is easier to reach with one hand.
- Remove the duplicate empty-state caption while retaining guidance inside the composer.
- Give the model selector a full-width row and place thinking, attachments, tool presets, More and send on the next row, with natural wrapping and 44px touch targets on narrow screens.
- Preserve the desktop centered welcome and composer layout.

### Desktop updater fix

- Recognize the release CI's actual `amd64` AppImage filename as well as `x86_64`, restoring the missing Linux updater entry.
- Although `desktop-v0.9.87` published its installers and signatures, its updater manifest omitted Linux. This release publishes a new manifest with signed Windows and Linux entries.
- CI now rejects incomplete updater manifests before publishing.
